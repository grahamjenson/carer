Warning, the app should not be used to make medical decisions. Use it at your own risk.


Guardian Monitor is an app that reads glucose values ​​from one of the available CGM services without changing any settings in the original service.


To use this app, you must have your own account with the original service, because authorization is required, without which the app will not work.


The app extends the standard functionality with its own alarm mechanism or voice reading of measurements.


In addition, it is possible to set the app to run in the background, by playing a wake-up sound, which will turn into an alarm if necessary.


Other features include:

- Apple Watch support (including eSIM)

- Widgets

- Siri support

- Nightscout sync

- Session sharing between devices
